## Description
This script calculates the orbital velocity of the ISS using the **J2 Perturbation Model**, which accounts for the Earth's oblateness (Geoid). Public data often oversimplifies these physics.

## Results
- **Calculated Velocity:** 27607.205628 km/h
- **Model:** Non-spherical Earth (J2 Coefficient)
